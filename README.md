# Tampermonkey Scripts

Koleksi userscript Tampermonkey untuk membantu otomatisasi tugas, kustomisasi antarmuka, dan peningkatan produktivitas saat menjelajah web.

## Instalasi

1. Install ekstensi Tampermonkey pada browser.
2. Pilih script yang ingin digunakan.
3. Klik file script (`.user.js`).
4. Install melalui Tampermonkey.
